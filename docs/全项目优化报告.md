### ✅ 问题2：task_engine.py 巨型文件拆分（3331 → 2488 行）

**改动**：拆出 3 个 Mixin 到 `core/task_engine_mixins/`：

| Mixin | 职责 | 行数 |
|---|---|---|
| ClickMixin | 点击/附加点击/坐标文件查找/模板解析 | 249 |
| YoloMixin | YOLO 检测/选目标/动作/兜底 | 368 |
| SwitchMixin | switch 条件分支执行 | 270 |

`TaskEngine` 改为 `class TaskEngine(ClickMixin, YoloMixin, SwitchMixin, QObject)`，单例 `task_engine`、`from core.task_engine import TaskEngine` **完全不变**。

**踩坑记录（重要）**：Mixin 拆分后，方法体内引用的模块级全局（如 `input_controller`）解析模块从 `core.task_engine` 变为 `core.task_engine_mixins.click_mixin`，导致测试 `@patch('core.task_engine.input_controller')` 失效。尝试过模块级 `__getattr__` 代理（对 LOAD_GLOBAL 不可靠），**最终正解**：`_do_click` 内改为运行时 `from core.task_engine import input_controller`（patch 生效且无循环导入）。

**验证**：`test_task_engine.py` **31/31 通过**（含点击/move/条件/重试；拆分前 6 个点击测试失败 → 修复后全绿）。
