### 1.4 已踩过的坑（新游戏专属，写代码时必须规避）

1. **`getmetatable(u).事件开始` 无效** —— 新游戏 NPC（钟馗）无此方法、无 metatable，必须走 PostMessage 点击坐标。
2. **`tp.地图.地图单位` 可能是键值结构** —— `#t==0` 但 `pairs` 有内容，用 `for i=1,#t` 会漏掉全部单位。
3. **`tp.战斗中` 恒为 nil** —— 永远 False，不能用。
4. **`tp.战斗类.背景显示` 脱战后残留** —— 垃圾数据，不能单独作为判据。

## 二、关键发现

### 发现 1：MPCG 只能做参考，不能做基础 ✅ 与你的判断一致

你判断「这是新游戏，操作上有所不同」——**已证实**。MPCG 的三张核心表
（`SECT_MAP_ID` 15 个地图 ID / `SECT_GUARD_COORDS` 15 个护法坐标 / `SECT_DESC_DIRECT` 8 条 desc）
全部基于旧游戏，且读取入口字段在新游戏不存在。**整体不可用。**

### 发现 2：门派闯关在新游戏是「未探索领域」

ZGUI.py 全量搜索 `护法|门派|闯关|使者` → **零命中**。
新游戏里没有任何门派闯关的既有代码，一切从零。

### 发现 3：抓鬼运行时，外部 Lua 探测 100% 超时 ⚠️ 阻塞

```
[try1] 10.02s ok=False  执行超时(10.0s)
[try2] 10.01s ok=False  执行超时(10.0s)
[try3] 10.04s ok=False  执行超时(10.0s)
队列: safe=3021  deferred=10126  starve=0  queueLen=9  hookDepth=3
```

`deferred/safe` ≈ 3.35，网关内部硬超时 10s。抓鬼高频调用把注入队列占满，
**任何外部 Lua 探测都挤不进去**。

→ **摸清门派闯关必须先停抓鬼（Ctrl+C）**。

### 发现 4：你要的其实是「编排器」，不是两个独立脚本

你描述的运行形态：

```
抓鬼 × 10 或 20 次  →  门派闯关（整轮）  →  抓鬼 × 10 或 20 次  →  ...
```

这是**串行调度**，天然解决了发现 3 的互斥问题——同一时刻只有一个在跑，
切换点由编排器控制，而不是靠两边互相让路。

## 三、实施方案

### 阶段 0 · 探索性实测（前置阻塞，需停抓鬼）

**目标**：把新游戏的门派闯关从黑盒变成白盒。

需要 dump 出的六件事：

| # | 待测项 | 探测路径 |
|---|---|---|
| 1 | 门派闯关任务在哪接 | 遍历 `tp.地图.npc` 找「闯关/使者」类 NPC；去长安点它看对话选项 |
| 2 | 任务栏里怎么显示 | `tp.窗口.任务栏.任务` 全量 dump（名称 + 说明） |
| 3 | **15 门派完整名单（已确认共 15 个）** | 接任务后从任务说明/对话选项提取 15 个门派名 |
| 4 | 怎么去各门派 | 传送 NPC 对话选项（跳转链接）/ 会员卡 |
| 5 | 护法叫什么、在哪 | `tp.地图.地图单位` + `tp.地图.npc` 按名匹配 |
| 6 | 完成判定 | 任务栏条目消失 / 完成弹窗文本 |

产出：`docs/production/S3-sect15-fieldmap.md`（字段地图）+ 门派名单表。

**前置**：Ctrl+C 停掉当前抓鬼（会输出本轮汇总）。

### 阶段 1 · 新建独立 CLI 模块

- 文件：`tasks/library/SECT15.py`（新文件，**不动 MPCG.py、不动 ZGUI.py**）
- 底座：只用新游戏字段树（1.3 节），**不 import MPCG**
- 结构（对齐 `MPCG_auto_round` 的三态分发，但换成新字段）：

```
状态轮询 → 战斗中等待 / 对话弹窗解析 / 空闲按任务栏自锚定
        → 定位目标门派 → 传送 → 找护法 → 开打 → 循环
        → 完成判定 → 回城 → 接下一轮
```

- CLI 能力（按你勾选的三项）：
  - ✅ jsonl 逐轮落盘 + `flush` + `fsync`（崩溃不丢已完成的轮）
  - ✅ Ctrl+C 优雅停止（打完当前关再退；再按一次强制中止）
  - ✅ 后台内存采样线程（整轮连续采样，事后可还原每关发生了什么）
  - ⬜ `--dry-run`（本轮未勾选，暂不做）

- 模板来源：`run_unlimited_test.py`（抓鬼的跑批器，成熟可抄）

### 阶段 2 · 编排器

- 文件：`run_dual.py`（新文件）
- 逻辑：

```
while True:
    跑抓鬼 N 轮（N 随机取自 [10, 20]）
    切到门派闯关，跑完整一轮
    回抓鬼
```

- 串行执行 → 天然满足发现 3 的互斥约束
- 复用各自的 jsonl 落盘，编排器自身另记一份切换日志
